# skala-vue-exercise

SKALA Vue.js 학습 저장소

## exercise/

SKALA 강의 종합실습 — Vue 3 Composition API 기반 날씨 대시보드

| 과제 | 내용 |
|------|------|
| 과제 1 | v-for, v-if/v-else, 한글 입력(:value/@input), 이벤트/수식어를 통합한 날씨 목업 |
| 과제 2-1 | Composition API로 리팩토링. computed로 검색 필터링, watch/watchEffect 실습 |
| 과제 2-2 | BaseDashboardCard / SearchBar / WeatherCard로 컴포넌트 분리 (props/emits) |
| 과제 3 | Vue Router(목록/상세), Pinia(섭씨·화씨 토글), Axios(OpenWeatherMap 실시간), Element Plus |
| 최종 개인과제 | 오뒷세우스 항로 실제 좌표에 실시간 날씨·파고 데이터를 입혀 출항 가능 여부를 판정하는 지도 페이지 |

## practice/

강의 중 Vue 3 핵심 개념을 직접 실습한 개인 연습 파일

| 폴더 | 내용 |
|------|------|
| directive/ | v-bind, v-model, v-for, v-if, v-on 등 주요 디렉티브 실습 |
| composition/ | ref, reactive, computed, watch, watchEffect 실습 |
| component/ | slot(default/named/scoped) 실습 |
| props-emits/ | 부모-자식 컴포넌트 간 props/emits 통신 |
| lifecycle/ | 라이프사이클 훅 실습 |
| modern-js/ | 비동기 처리, 배열 메서드 등 모던 JS 미션 |
| library/ | Axios, Pinia 등 외부 라이브러리 연동 |
| ui-library/ | Element Plus UI 컴포넌트 활용 |
